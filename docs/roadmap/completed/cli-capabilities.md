# CLI 能力

**状态：已完成并持续维护**

CLI 当前提供：

- PDF scan、导入、完整 pipeline、恢复和强制重建。
- 独立 Metadata、Full text、Abstract、Summary 和 Outline 命令。
- Provider 和配置诊断。
- Paper 查询和 artifact 检查。
- Tag 和有序 Collection 管理。
- 数据库初始化、migration、备份、artifact 检查和日志清理。
- 稳定的进度、warning、failure、退出码和 LLM usage 输出。

命令行为见 [CLI 运行指南](../../user/operations.md)。
