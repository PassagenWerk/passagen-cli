## 计划中

CLI 的未来命令只在对应 Core contract 明确后规划。Paper/Collection 问答、Collection
synthesis、研究报告和结构化问答归档的命令及分阶段方案见 Passagen Core 的
`docs/roadmap/planned/collection-research-and-exploration.md`。CLI 只负责同步调用、进度、
退出码和 Markdown/JSON 输出，不单独实现 prompt、检索或引用逻辑。
